## 2. 实施内容

新增 `sandbox-api/idle_detection.py`，由 `IdleDetector` 统一输出 `IdleDecision`：

- `last_active_at` / `created_at` 计算持久化活动信号年龄；
- WebSocket 活跃连接计数直接阻止休眠；
- 缺失或非法活动信号返回 `activity_signal_missing`，保守选择不休眠；
- 扫描初判与拿 lease 后二次校验使用同一裁决；
- `AUTO_SLEEP_IDLE_S`、`ACTIVITY_TOUCH_MIN_S` 只有一处声明。

接入路径：

| 路径 | 活跃处理 |
|---|---|
| HTTP `/s/{sid}/{port}/` | 延续节流刷新 |
| `POST /exec` | 延续节流刷新 |
| WebSocket | 建连/断连强制刷新；传输或安静连接心跳刷新；连接计数即时阻断 |
| 文件上传/下载 | 开始刷新，完成后强制刷新 |

`scripts/autosleep_e2e.sh` 新增 A6：WebSocket 保持超过 idle 阈值仍为
`running`，断开并超过 idle 窗口后才进入 `slept`。

- 无 Bearer key 返回 401；

### 5.2 空闲检测 A0-A6

| 用例 | 结果 | 证据 |
|---|---|---|
| A0 能力检查 | PASS | `suspend_resume=True` |
| A1 创建 opt-in sandbox | PASS | `web` guest 进入 `running` |
| A2 真正空闲自动休眠 | PASS | 状态为 `slept`，事件含 `reason=idle` |
| A3 网关透明唤醒 | PASS | 首请求 200，恢复 `running`，耗时 `1.841172s` |
| A4 exec 活动保活 | PASS | 持续保活 50s 后仍为 `running` |
| A5 手动暂停区分 | PASS | `suspended` 不被网关唤醒，返回 409 |
| A6 WebSocket | PASS | 长连接 40s 仍运行；断开后按 idle 阈值进入 `slept` |

第一次执行 A6 曾报告失败。检查客户端日志后确认测试服务并未启动：
rootfs 中 `nohup python3` 无法解析可执行文件，客户端实际收到
`Connection refused` 后退出，并非产品逻辑误睡。脚本改为使用绝对路径
`/usr/local/bin/python3` + `setsid`，并在计时前验证 exec 返回、8080 监听状态和
客户端进程存活；重跑后 A0-A6 全部通过。该修正确保 A6 不会产生假阴性或假阳性。
