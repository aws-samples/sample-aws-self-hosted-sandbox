> Region：`us-east-1`
> EKS：`claude-sbx`
> 数据节点：Intel x86 `i7i.8xlarge`
> 结论：CloudWatch 集中日志、跨组件 X-Ray tracing、AMG 自动配置与凭据清理均通过。
> AWS 环境按要求保留。

## 一、实施范围

- Fluent Bit DaemonSet，经 IRSA 写 `/aws/eks/claude-sbx/sandbox-platform`
- ADOT Collector 双副本，经 IRSA 写 AWS X-Ray
- control-plane/node-agent 手工 OpenTelemetry server/client span 与 `traceparent` 传播
- JSON 日志增加 `request_id`、`trace_id`、`span_id`
- AMG datasource/Dashboard 使用 15 分钟临时 service-account token 自动 upsert
- 旧快照 manifest 首次恢复迁移，以及 base 文件 SHA-256 缓存

AMG workspace、AMP workspace 与 PrivateLink 复用 P1 环境，不创建新 workspace。
Alertmanager 外部通知接收器不在本轮范围。

## 三、安全与兼容性

- Fluent Bit 仅可写目标 Log Group。
- ADOT 仅具 X-Ray 写入与采样读取权限。
- AMP PrivateLink 入站仅允许 AMG workspace 安全组，不再放行整个 VPC CIDR。
- AMG token 不写文件或日志；脚本用 `trap` 删除 token 和 service account。
- 历史快照没有 `integrity.json` 时会在首次恢复前生成并立即校验，同时记录迁移指标。
- 迁移只能为后续变化建立基线，无法证明迁移前的历史文件未损坏；日志使用 warning 标识。
- base 快照 hash 缓存以 device/inode/size/mtime/ctime 为键，文件变化后自动失效。
